# Dictionary data attribution

The Android APK build downloads and embeds the Italian–Portuguese dictionary from FreeDict/WikDict, release 2025.11.23 (12,762 reported headwords).

Source: https://freedict.org/ and https://download.freedict.org/dictionaries/ita-por/2025.11.23/
